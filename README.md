# MobaXterm 简体中文汉化补丁

本项目为 MobaXterm 官方版本提供可审查、可重建的简体中文资源补丁。

## 版本目录

每个版本独立放在对应目录，例如 `26.4/`。后续版本使用新的目录（如 `26.5/`），不覆盖旧版本。

## 参考来源与致谢

- MobaXterm 23.0 简体中文项目：[RipplePiam/MobaXterm-Chinese-Simplified](https://github.com/RipplePiam/MobaXterm-Chinese-Simplified)。本项目参考其部分中文术语、界面译法和翻译组织方式。
- 52 破解相关资料：[作者主页](https://www.52pojie.cn/?1222738)。本项目参考其中关于 `.rsrc` 界面资源重建、资源重排和菜单布局处理的技术思路。

以上内容仅作为翻译和技术研究参考。本项目没有直接移植上述项目或文章中的 EXE、插件、代码段、`.movehcs` 文件或其他二进制；当前实现基于合法取得的官方原版文件独立构建。

## 安全原则

仓库只发布脚本、翻译表和说明文档，不发布官方 MobaXterm EXE、官方插件或第三方汉化二进制。使用者应从合法来源取得对应版本原版文件，在本地运行构建脚本，并自行核对 SHA-256。

修改后的程序不再保留 Mobatek 原始数字签名。请先阅读对应版本目录中的说明，再进行构建和测试。
